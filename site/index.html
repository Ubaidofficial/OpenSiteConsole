02Product

Not another dashboard to stare at.

Every screen is built to end in a decision: what to fix, what changed, whether it worked.

  1. 01

    A ranked to-do list.

    Broken tracking, blocked or de-indexed pages, traffic collapses, cannibalisation, CTR gaps, striking distance: every finding in one list. Blocking items first, then by estimated clicks times confidence. Hover any chip to see what it means.

    ranked · explained · per site or across all

  2. 02

    Every site, one list.

    Portfolio merges striking distance, cannibalisation, decay and anomalies across all your properties and Google accounts. Each site is judged on its own data first, then merged.

    many accounts · duplicates counted once

  3. 03

    Every source, side by side.

    Google, Bing, GA4 and Clarity joined on the page’s URL path, with www, http and https counted as one page. Each metric carries its change against the previous period.

    Search Console · Bing · GA4 · Clarity

  4. 04

    Numbers fitted to your site.

    Striking-distance queries ranked by estimated extra clicks, using a click-through curve fitted to your own data instead of an industry average. Bold means measured on your site; grey means a fallback.

    your CTR curve · not a benchmark

  5. 05

    Test what you change.

    Before and after, split with control pages, or redirect tests, with a 95% interval, a p-value and a plain verdict. A test that wins on clicks but loses key events is flagged, not celebrated.

    clicks and GA4 key events

  6. 06

    Know when Google forgets a page.

    An opt-in monitor re-inspects your biggest pages every day and logs de-indexed, newly indexed, canonical changes and robots blocks, so a quiet drop does not stay quiet.

    URL Inspection · daily · opt-in

05Questions

Straight answers.

Is it really free?

Yes. It is open source under the AGPL-3.0 licence and free to self-host, with every feature included. A hosted plan at $10 a month is planned, and the page above says plainly that it is not open yet.

What can an AI agent do with it?

Read. The MCP server exposes 29 read-only tools over your stored search data: performance, opportunities, indexing, tracking health and more. An agent cannot change your Search Console, your sites or your settings. Live URL inspections are rate-limited and have a daily budget per key.

Where does my data live?

In a SQLite file on the server you run it on. Google sign-in tokens are encrypted at rest with AES-256-GCM. Whatever an agent reads is sent to that agent’s provider, so connect only agents you trust with that data.

How far back does history go?

As far as Google provides when you first connect, up to 16 months, and then it keeps everything it syncs from that day on. It cannot recover data Google no longer has.

Which AI clients work?

Claude’s custom connector works with one-click sign-in, and Claude Code works with a single command. Any MCP client that speaks HTTP with a bearer token or OAuth should work, but only Claude has been confirmed.

How mature is it?

Early. It has more than 500 automated tests and browser checks on demo data, and sign-in with Claude has been confirmed end to end. Verification on real accounts is ongoing, so expect rough edges and please report them.
