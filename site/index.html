Many sites, many accounts

Every website. One dashboard.

Connect every Google account you use, whether that is yours, a client’s or an old agency login. Each property is listed once, with the change against the previous period on every number.

  • One to-do list across all your sites, blocking problems first.
  • Duplicates counted once. A domain property and its URL-prefix twin don’t double your numbers.
  • Privacy mode blurs site names for screenshots and screen-shares. The numbers stay visible.
  • The same data in Claude, so one question can cover every site.

How it works

Every screen ends with what to do next.

Fewer charts to interpret. Each view answers one question: what to fix, what changed, or whether your last change worked.

  1. 01

    A plan for the next two weeks.

    Every site report opens on what to do next: problems that stop you earning first, then quick wins, then bigger opportunities. Each has its first step and its estimated clicks, and one tick marks it done. The full ranked list is a click away.

    blocking first · quick wins · bigger opportunities

  2. 02

    Every site, one list.

    Portfolio merges striking distance, cannibalisation, decay and anomalies from every property and Google account. Each site is judged on its own data first, then the lists are merged.

    many accounts · duplicates counted once

  3. 03

    Every source, side by side.

    Google, Bing, GA4, AI-assistant visits and Clarity in one table, joined on the page. www, http and https count as one page, and each number shows its change against the previous period.

    Search Console · Bing · GA4 · Clarity

  4. 04

    Numbers fitted to your site.

    Striking-distance queries ranked by estimated extra clicks, using a click-through curve fitted to your own data instead of an industry average. Bold means measured on your site. Grey means a fallback.

    your CTR curve · not a benchmark

  5. 05

    Did that change work?

    Log a change and SEOConsole compares the pages you touched with matched control pages over the same days. You get a 95% range, a p-value and a plain verdict, including “no clear effect” when the data can’t tell. A test that wins clicks but loses key events gets flagged.

    before/after · split · redirect tests

  6. 06

    Know when Google drops a page.

    An opt-in monitor re-inspects your biggest pages every day and logs pages that were de-indexed, newly indexed, given a new canonical or blocked by robots. A quiet drop doesn’t stay quiet.

    URL Inspection · daily · opt-in

REST API

Plug it into anything.

Every tool your agent uses is also a REST endpoint, with the same keys, site limits and permissions. Pull your data into a spreadsheet, a dashboard or a script.

GET /api/v1/get_quick_wins?site=1
Authorization: Bearer osc_…
  • GET /api/v1lists every endpoint
  • GETreads, nothing changes
  • POSTacts, only if the key allows

What it doesn’t do

  • No rank tracker or backlink index of its own. It works from what Google, Bing, GA4 and Clarity already know about your sites; if you run OpenSEO, it hands your best searches to OpenSEO’s rank tracker.
  • No AI writing. It tells you which page to work on and why. The changes are yours to make.
  • No history from before you connect beyond the 16 months Google still holds on that day.
  • No hosted version yet. You run it yourself, on your computer or a server.

FAQ

Common questions.

Is it really free?

Yes. It is open source under the AGPL-3.0 licence and free to self-host, with every feature included. A hosted plan at $9 a month is planned but not open yet.

What can an AI agent do with it?

Read first. The MCP server has 42 tools that read your stored search data, and 20 that can change things: mark a finding done, log a change, start a test, refresh data, run page checks, send URLs to Bing through IndexNow or Bing's own submission API, submit a sitemap, ask for indexing checks, set brand terms, watch URLs. Those 20 refuse unless you gave that connection the submit level, which is off by default. A separate delete level, also off by default, adds only two things: removing a sitemap from Search Console and discarding queued submissions, each after a second, confirming call. Nothing can delete your search data, connect accounts, or touch keys and passwords, and every change is written to an audit log. Live URL inspections are rate-limited and have a daily budget per key. The same tools are also a plain REST API, with the same keys and permissions.

Where does my data live?

In a SQLite file on the server you run it on. Google sign-in tokens are encrypted at rest with AES-256-GCM. Whatever an agent reads is sent to that agent’s provider, so connect only agents you trust with that data.

How far back does history go?

As far as Google provides when you first connect, up to 16 months, and then it keeps everything it syncs from that day on. It cannot recover data Google no longer has.

Which AI clients work?

Claude’s custom connector works with one-click sign-in, and Claude Code works with a single command. Any MCP client that speaks HTTP with a bearer token or OAuth should work, but only Claude has been confirmed.

How is it different from Google Search Console?

It reads from Search Console, so it does not replace it. It puts every property and Google account in one place, keeps history past 16 months, adds Bing, GA4 and Clarity, and turns the data into a ranked to-do list, SEO tests and a weekly digest. Search Console keeps tools SEOConsole does not copy, such as Removals, Manual actions, Security issues, the Links report and the Request Indexing button itself.

How does it compare with SEOTesting.com?

Both run before/after, split and redirect tests on Search Console data, with a control group and a significance figure; both have LLM tests on AI-assistant sessions from Google Analytics, an internal-linking tool and unlimited users. SEOTesting.com is hosted and costs from $50 a month (its pricing page, read on 7 November 2026), and its internal-linking reports use a monthly credit allowance. SEOConsole is free to self-host for any number of sites, with no credits, adds Bing, Clarity, Tag Manager, an indexing toolkit and an MCP server, and keeps your data on your own server.

Can I just ask it questions instead of reading reports?

Yes. The Ask page in your dashboard is a chat: ask “why did clicks drop?” or “which titles should I rewrite?” and it answers from your own data, with tables and charts, using the same tools as the MCP server. It runs on Claude with your own Anthropic API key, so messages are billed to your account and capped per person per day. It acts as you: a viewer’s chat only reads, and for everyone else each change is shown with Approve and Decline before it runs. It is new and has been tested against a stand-in for the API, not yet on a live key.

Can it track what AI assistants say about my brand?

Yes. The AI answers tab puts the questions you choose to ChatGPT, Gemini, Claude and Perplexity every week, with web search on, and records whether your brand is mentioned, whether your pages are cited, and which competitors appear. It covers the essentials; dedicated tools such as Promptwatch go deeper. It uses your own API keys, or one DataForSEO login that also reads ChatGPT and Gemini as people see them in the apps. Every run is billed to your account, so runs are capped per day. It is new and has been tested against each provider’s documented responses, not yet on live accounts.

Does it work with OpenSEO?

Yes. Connect your OpenSEO address and API key and each site is linked to its OpenSEO project by domain. Then you get search volume next to your own queries, your best striking-distance searches sent to OpenSEO’s rank tracker after a free cost preview, and OpenSEO’s latest site audit in your to-do list, on the pages that earn clicks. It was checked against a live self-hosted OpenSEO.

How long does setup take?

About 20 minutes once the Google sign-in is configured. A set-up guide on the dashboard walks through nine steps in three phases, ticks each one off by itself, and does some in one click, such as switching on the indexing monitor.

How mature is it?

Early. It has more than 1,000 automated tests and browser checks on demo data, and sign-in with Claude has been confirmed end to end. Verification on real accounts is ongoing, so expect rough edges and please report them.
