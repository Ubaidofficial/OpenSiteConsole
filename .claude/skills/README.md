# Skills in this repository

Five skills are copied **unchanged** from [every-app/seo-party-skills](https://github.com/every-app/seo-party-skills)
at commit `e3f4ce75ec0be97d2f40912006451806a67b45c4` (MIT, see `LICENSE-seo-party-skills`):
`competitor-strategy`, `customer-keywords`, `free-tool`, `keyword-gap`, `rank-on-ai`.
They are experimental and not official OpenSEO skills. Each needs the **OpenSEO MCP server** connected; they spend OpenSEO credits.
To update them, re-copy from upstream and change the commit above. Do not edit the copies: put changes in a new skill instead.

One skill is ours:

- `keyword-gap-first-party`: the keyword-gap workflow, but the site's own side comes from SEOConsole (Search Console history) instead of an estimate.

For these skills to see your site, connect **both** MCP servers (SEOConsole and OpenSEO) to the agent.
